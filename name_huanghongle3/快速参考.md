# Jetson 服务管理 - 快速参考

> **更新到最新版**：相机已启用深度/红外/点云；HTTP 提供 /camera、/depth、/ir 三路流；推荐交互式管理器 `robot_service_manager.py`（v2.0）。

## 🚀 启动方式

### 方式 1：交互式管理器（推荐，功能最全）
```bash
cd /home/nvidia/name_huanghongle
python3 robot_service_manager.py
```
- 交互式菜单，选择服务启动/停止，自动处理依赖
- `1-6` 启动/停止对应服务，`s1-s6` 仅启动，`k1-k6` 仅停止
- `a` 全部启动，`o` 全部停止，`r` 重启，`l` 查看日志，`q` 退出
- 启动前检查进程/端口/话题冲突

### 方式 2：一键启动脚本（Bash，轻量）
```bash
cd /home/nvidia/name_huanghongle
./quick_start.sh
```
- 纯 Bash 脚本，无需 Python 依赖
- 自动清理旧进程
- 自动检查端口占用
- 自动验证启动结果

### 方式 3：Python 管理器（旧 start_all_services.py，已非首选）
```bash
cd /home/nvidia/name_huanghongle
python3 start_all_services.py        # 启动所有
python3 start_all_services.py status # 查看状态
python3 start_all_services.py stop   # 停止所有
```

## 🌐 前端接入地址

HTTP 视频服务器提供 **3 路 MJPEG 流**（前端 `<img>` 直连，不经过 rosbridge）：

| 服务 | 地址 |
|:---|:---|
| 彩色视频流 | `http://192.168.0.2:8082/camera`（/camera/color/image_raw） |
| 深度流 | `http://192.168.0.2:8082/depth`（/camera/depth/image_raw，16UC1→归一化灰度） |
| 红外流 | `http://192.168.0.2:8082/ir`（/camera/left_ir/image_raw，16UC1→归一化灰度） |
| ROS WebSocket | `ws://192.168.0.2:9090` |
| 超声波 Topic | `/wave_length` |

```html
<!-- HTML -->
<img src="http://192.168.0.2:8082/camera" alt="Camera" />
<img src="http://192.168.0.2:8082/depth" alt="Depth" />
<img src="http://192.168.0.2:8082/ir" alt="IR" />

<!-- Vue -->
<img :src="cameraUrl" @load="onCameraLoad" />
data() {
  return { cameraUrl: 'http://192.168.0.2:8082/camera' }
}
```

> 节点会剥离 URL 查询串（`urlparse(self.path).path`），前端追加 `?t=...` 时间戳也能正确匹配。前端页面可一键切换 彩色/YOLO 识别/深度图/红外图，全部通过 HTTP 直连。

## ⚠️ 常见问题

### 1. 端口被占用
```bash
# 查看占用端口的进程
ss -tlnp | grep 8082
fuser -k 8082/tcp  # 杀死占用进程
```

### 2. 相机启动失败
```bash
# 检查 USB
tail -f /tmp/camera.log
lsusb | grep Orbbec
```

### 3. HTTP 流无法访问
```bash
# 本地测试
curl http://localhost:8082/camera -o /tmp/test.jpg
ls -lh /tmp/test.jpg
```

### 4. 权限不足
```bash
chmod +x /home/nvidia/name_huanghongle3/*.sh
chmod +x /home/nvidia/name_huanghongle3/*.py
```
