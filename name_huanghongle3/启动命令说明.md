# Jetson 服务启动管理器

> **更新到最新版**：深度/红外已启用；推荐使用交互式管理器 `robot_service_manager.py`（v2.0）。

## 📁 文件位置
- 主脚本（推荐）: `/home/nvidia/name_huanghongle3/robot_service_manager.py` （交互式管理器 v2.0）
- 旧脚本: `/home/nvidia/name_huanghongle3/start_all_services.py` （仍可用，但已非首选）

## 🚀 使用方法

### 1.（推荐）交互式服务管理器
```bash
cd /home/nvidia/name_huanghongle
python3 robot_service_manager.py
```
进入后支持以下操作（可直接在内网或 SSH 中使用）：
- `1-6`：启动/停止对应服务（按当前状态切换）
- `s1-s6`：仅启动指定服务（如 `s3` 启动 HTTP 视频流）
- `k1-k6`：仅停止指定服务（如 `k4` 停止 STM32 控制）
- `a`：启动所有服务；`o`：停止所有服务；`r`：重启所有服务
- `l`：查看日志；`q`：退出

管理器会自动处理依赖关系（HTTP 依赖相机、STM32/超声波依赖 ROS Bridge、定位依赖 ROS+超声波），并对内存占用过高的启动进行二次确认。

### 2. 一键启动所有服务（旧脚本，仍可用）
```bash
cd /home/nvidia/name_huanghongle
python3 start_all_services.py
```

### 3. 查看当前状态
```bash
python3 start_all_services.py status
```

### 4. 停止所有服务
```bash
python3 start_all_services.py stop
```

### 5. 帮助
```bash
python3 start_all_services.py help
```

## 📋 启动的服务

| 服务 | 说明 | 端口/话题 |
|:---|:---|:---|
| 相机 (Orbbec) | 双目相机驱动，已启用深度/点云/双目红外 | Topic: /camera/color/image_raw、/camera/depth/image_raw、/camera/left_ir/image_raw、/camera/right_ir/image_raw |

## 🛠️ 故障排除

### 服务启动失败
1. 查看日志文件
2. 检查端口占用：`ss -tlnp | grep 8082`
3. 检查进程：`ps aux | grep camera`

### 手动清理残留进程
```bash
# 停止相机
pkill -f "gemini_330_series"
pkill -f "component_container"

# 停止 HTTP
pkill -f "camera_http_node"

# 停止 ROS Bridge
pkill -f "rosbridge_websocket"

# 停止超声波
pkill -f "wave_length_node"
```

### 检查服务状态
```bash
# 查看相机话题
ros2 topic info /camera/color/image_raw

# 查看超声波话题
ros2 topic info /wave_length

# 测试 HTTP 流
curl http://localhost:8082/camera -o /tmp/test.jpg

# 测试 ROS 连接
ros2 topic list
```

## 📝 前端接入地址

HTTP 视频服务器（端口 8082）现提供 **3 路 MJPEG 流**，前端用 `<img>` 直接访问，**不经过 rosbridge 转发视频**（避免占用 rosbridge 内存/CPU）：

```html
<!-- 彩色流（/camera/color/image_raw） -->
<img src="http://192.168.0.2:8082/camera" alt="Camera" />

<!-- 深度流（/camera/depth/image_raw，16UC1 归一化灰度） -->
<img src="http://192.168.0.2:8082/depth" alt="Depth" />

<!-- 红外流（/camera/left_ir/image_raw，16UC1 归一化灰度） -->
<img src="http://192.168.0.2:8082/ir" alt="IR" />

<!-- ROS 连接 -->
<script>
const ros = new ROSLIB.Ros({ url: 'ws://192.168.0.2:9090' });
</script>
```

> 说明：节点会剥离 URL 查询串（`urlparse(self.path).path`），因此前端追加 `?t=...` 时间戳也能正确匹配，不会 404。前端 `<img>` 可追加 `?t=${Date.now()}` 强制刷新而无需改地址。

## ⚠️ 注意事项

1. **启动顺序很重要** - 必须先启动相机，再启动 HTTP 服务器
2. **端口占用** - 8082 和 9090 不能被其他程序占用
3. **权限** - 可能需要 `chmod +x` 赋予执行权限
4. **后台运行** - 脚本默认前台运行，按 Ctrl+C 停止
5. **相机已启用深度/点云/双目红外** - 深度、左右红外分辨率均为 640x400@10fps，彩色为 1280x720@10fps
