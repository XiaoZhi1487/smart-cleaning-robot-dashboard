## 项目概述

### 项目背景
本项目是一个基于 **Vue 3 + ROS 2** 的智能清洁机器人数据可视化监控系统。系统通过 WebSocket 实时接收来自 NVIDIA Jetson Orin Nano Super 的传感器数据，并在 Web 页面上进行可视化展示，用于监控清洁机器人的运行状态、环境感知和污渍检测。

### 核心功能
- **数据大屏**：设备状态总览、机器人作业视图、今日作业统计（ECharts）、实时工作日志
- **机器人控制**：Web 端方向键 / WASD 遥控清洁机器人（前进、后退、左转、右转、停止）
- **超声波测距监控**：4 路超声波传感器数据实时显示 + Canvas 雷达可视化，用于边缘检测和避障
- **STM32 指令下发**：通过 ROS 话题向 STM32 下发行走与清扫指令并回显结果
- **深度相机 / 工业相机监控**：YOLO 污渍识别服务对相机视频流逐帧标注，前端直接显示带标注流
- **多语言国际化**：中文 / English / ไทย / Bahasa Melayu / Bahasa Indonesia / Tiếng Việt 六语言切换

### 技术栈
- **前端框架**：Vue 3 + Vue CLI
- **状态管理**：Pinia（全局 ROS 连接状态）
- **国际化**：vue-i18n
- **图表可视化**：ECharts 6
- **通信协议**：WebSocket（roslib.js 连接 ROS 2）
- **相机 AI 标注**：YOLO（ultralytics）+ OpenCV + Flask（Python 后端）
- **传感器转发**：Python（websockets / asyncio）
- **后端/机器人**：ROS 2 Humble (Robot Operating System 2)
- **硬件平台**：NVIDIA Jetson Orin Nano Super

## 核心代码解析

### 超声波雷达组件 (UltrasonicRadar.vue)

#### 数据解析核心代码

```javascript
// ============ 核心：数据解析函数 ============

const processSensorData = (message) => {
  // 从消息中提取数据
  let data = message.data
  
  console.log('Raw data:', data, 'Type:', typeof data)
  
  // ----- 关键步骤 1: Base64 解码 -----
  // rosbridge 将二进制数据编码为 Base64 字符串传输
  if (typeof data === 'string') {
    console.log('Data is Base64 string, decoding...')
    
    try {
      // atob() 函数解码 Base64
      const binaryString = atob(data)
      
      // 转换为 Uint8Array
      const bytes = new Uint8Array(binaryString.length)
      for (let i = 0; i < binaryString.length; i++) {
        bytes[i] = binaryString.charCodeAt(i)
      }
      
      // 转为普通数组
      data = Array.from(bytes)
      
      console.log('Decoded data:', data)
    } catch (error) {
      console.error('Base64 decode error:', error)
      return
    }
  }
  
  // 验证数据格式
  if (!data || !Array.isArray(data)) {
    console.error('Invalid data format:', data)
    return
  }
  
  if (data.length < 8) {
    console.warn('Data length too short:', data.length)
    return
  }
  
  // ----- 关键步骤 2: 字节解析 -----
  console.log('Parsing sensor data...')
  
  try {
    // 解析 4 个传感器的数据（电应普 A22）
    for (let i = 0; i < 4; i++) {
      // 获取高低字节
      const byte1 = data[i * 2]
      const byte2 = data[i * 2 + 1]
      
      // 确保是数字并转为无符号字节
      const highByte = Number(byte1) & 0xFF
      const lowByte = Number(byte2) & 0xFF
      
      // 组合成 16 位整数（大端序）
      // 公式: 距离 = 高字节 * 256 + 低字节
      // 位运算: (highByte << 8) | lowByte
      const distance = (highByte << 8) | lowByte
      
      console.log(`Sensor ${i}: bytes=[${byte1}, ${byte2}], high=${highByte}, low=${lowByte}, distance=${distance}mm`)
      
      // 更新传感器数据（Vue 响应式）
      if (isNaN(distance)) {
        console.error(`Sensor ${i}: Invalid distance`)
        sensors.value[i].distance = 0
      } else {
        sensors.value[i].distance = distance
      }
    }
    
    // 添加日志记录
    addLogEntry()
    
  } catch (error) {
    console.error('Error parsing sensor data:', error)
  }
}
```

```javascript
const detectObstacles = (ranges) => {

  ranges.forEach((range, i) => {

        index: i
      })
    }
  })
  
  // 按距离排序，只保留最近的 10 个障碍物
```

```javascript
const depthToColor = (depth) => {
  const maxDepth = 10.0
  const normalized = Math.min(depth / maxDepth, 1.0)
  
  // 热力图配色：深蓝 -> 青色 -> 绿色 -> 黄色 -> 红色
  if (normalized < 0.25) {
    // 深蓝到青色
    return {
      r: 0,
      g: Math.floor(255 * normalized / 0.25),
      b: 255
    }
  } else if (normalized < 0.5) {

    return {
      r: 0,
      g: 255,
      b: Math.floor(255 * (1 - (normalized - 0.25) / 0.25))
    }
  } else if (normalized < 0.75) {
    // 绿色到黄色
    return {
      r: Math.floor(255 * (normalized - 0.5) / 0.25),
      g: 255,
      b: 0
    }
  } else {
    // 黄色到红色
    return {
      r: 255,
      g: Math.floor(255 * (1 - (normalized - 0.75) / 0.25)),
```

## 关键技术点

### 1. Base64 编解码原理

```
为什么需要 Base64？
═══════════════════════════════════════════════════════════════

WebSocket 协议只能传输文本数据，而 ROS 2 的二进制数据无法直接传输。
Base64 将二进制数据编码为 ASCII 字符串（A-Z, a-z, 0-9, +, /, =）

编码过程:
原始二进制: [0x01, 0xF4, 0x00, 0xC8]
           │
           │ 每3字节(24位)分为4组，每组6位
           ▼
000000 011111 010100 000000 11001000
   │      │      │      │
   ▼      ▼      ▼      ▼
   0     31     20      0     200
   │      │      │      │
   ▼      ▼      ▼      ▼
  'A'    'f'    'U'    'A'   'Q'  (Base64字符表)
           │
           ▼
编码结果: "AfUA" + "Q==" (补位)

解码过程:
"AQX0AMgCWAEs"
   │
   ▼ atob() 函数
[0x01, 0xF4, 0x00, 0xC8, 0x02, 0x58, 0x01, 0x2C]
```

### 2. 字节序（Endianness）

```
大端序 vs 小端序
═══════════════════════════════════════════════════════════════

数值: 500 (0x01F4)

大端序 (Big Endian) - 网络协议、ROS 2 使用
内存地址: 低 -> 高
数据:     [0x01] [0xF4]
          高字节  低字节

小端序 (Little Endian) - x86 CPU 使用
内存地址: 低 -> 高
数据:     [0xF4] [0x01]
          低字节  高字节

本项目使用大端序（高字节在前）:
const highByte = data[0]  // 0x01
const lowByte = data[1]   // 0xF4
const distance = (highByte << 8) | lowByte  // 0x01F4 = 500
```

### 3. Canvas 绘图坐标系

```
Canvas 2D 坐标系
═══════════════════════════════════════════════════════════════

    0,0 ──────────────────────────────→ X (width)
    │
    │
    │
    │
    │
    ↓
    Y (height)

极坐标转直角坐标:
    x = centerX + Math.cos(angle) * radius
    y = centerY + Math.sin(angle) * radius

角度定义（弧度）:
    0°   = 0          = 右方向
    90°  = π/2        = 下方向
    180° = π          = 左方向
    270° = 3π/2       = 上方向
    360° = 2π         = 回到右方向

本项目传感器方向:
    前: -90° (-π/2)
    右: 0°   (0)
    后: 90°  (π/2)
    左: 180° (π)
```

### 4. Vue 3 响应式系统

```
Vue 3 响应式原理
═══════════════════════════════════════════════════════════════

ref() - 创建响应式引用
┌─────────────────┐
│  ref(0)         │
│  ┌───────────┐  │
│  │ value: 0  │  │ <-- 响应式对象
│  │ dep: Set  │  │ <-- 依赖收集
│  └───────────┘  │
└─────────────────┘

当 value 变化时:
1. 触发 setter
2. 通知 dep 中的所有依赖（组件渲染函数）
3. 组件重新渲染
4. 更新 DOM

computed() - 创建计算属性
┌─────────────────────────┐
│  computed(() => {       │
│    return a.value + b   │
│  })                     │
│  ┌───────────────────┐  │
│  │ value: 计算结果    │  │
│  │ deps: [a, b]      │  │ <-- 自动追踪依赖
│  │ dirty: true/false │  │ <-- 缓存标记
│  └───────────────────┘  │
└─────────────────────────┘

优势:
- 自动依赖追踪
- 惰性计算（只有依赖变化时才重新计算）
- 缓存结果（多次访问不重复计算）
```

## 调试与优化

### 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 无法连接 rosbridge | IP/端口错误 | 检查 Jetson IP (192.168.0.2) 和端口 (9090) |
| 数据为 NaN | Base64 解码错误 | 检查数据格式，确保使用 atob() 解码 |
| 无数据显示 | 话题名称错误 | 确认 ROS 话题名称和消息类型匹配 |
| 画面卡顿 | 渲染性能问题 | 减少 Canvas 绘制频率，使用 requestAnimationFrame |
| 内存泄漏 | 未清理资源 | 在 onUnmounted 中取消订阅和动画帧 |
| 超声波数据异常 | UART配置错误 | 检查波特率 (默认115200) 和串口设备 |
| 激光雷达无数据 | USB权限问题 | 添加 udev 规则，赋予 USB 设备权限 |
| 深度相机连接失败 | USB带宽不足 | 使用 USB 3.0 接口，降低分辨率或帧率 |
