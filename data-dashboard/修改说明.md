# Vue 项目界面优化修改说明

> ⚠️ **历史归档文档**：本文档记录某次界面布局优化的过程与改法，仅供参考。当前项目的最新功能、目录结构与运行方式请以 [项目书.md](./项目书.md) 为准。

## 一、问题分析

### 1. 布局冲突问题

| 文件 | 问题描述 |
|------|----------|
| `App.vue` | `.glass-panel` 的 `min-height` 和 `overflow: visible` 导致内容溢出；侧边栏和内容区的 `overflow` 设置冲突 |
| `UltrasonicRadar.vue` | `#debug-info` 和 `#data-log` 设置 `grid-column: 1 / -1` 导致跨列问题；模块高度使用 `fit-content` 不一致 |
| `LidarViewer.vue` | `#lidar-visual` 设置 `grid-row: 1 / 3` 导致高度计算问题；Canvas `min-height: 600px` 过大 |
| `DepthCamera.vue` | 类似问题，`#data-log` 跨列；`.image-container` 的 `min-height: 400px` 过大 |
| `Screen1.vue` | 使用 `grid-area` 定义位置，在小屏幕上可能导致模块重叠；`grid-auto-rows` 导致高度不一致 |

### 2. 美观问题

- 页面标题过于突出（60px高度），占用太多空间
- 连接面板元素间距过大
- 模块标题栏高度不一致（40px vs 36px）
- 统计信息展示方式不统一
- 空状态提示样式简陋
- 日志区域高度不固定

```diff

+ .main-content { overflow: hidden; }
```

```css

```

## 三、UltrasonicRadar.vue 修改内容

### 3.1 布局重构

**原布局（有问题）：**
```css
.monitor-grid {
  grid-template-columns: repeat(2, 1fr);
  grid-template-rows: auto auto;
}
#debug-info { grid-column: 1 / -1; }  /* 跨两列 */
#data-log { grid-column: 1 / -1; }    /* 跨两列 */
```

**新布局（修复）：**
```css
.monitor-grid {
  grid-template-columns: 1fr 1fr;
  grid-template-rows: 1fr 1fr;  /* 明确的2x2网格 */
  gap: 12px;
}
/* 移除跨列设置，每个模块独立 */
.radar-module { grid-row: span 2; }  /* 雷达图占左侧两格 */
```

### 3.2 视觉优化

| 优化项 | 修改内容 |
|--------|----------|
| 页面标题 | 改为 `page-header` 布局，标题和副标题并排 |
| 连接面板 | 使用 `input-wrapper` 包装输入框，更紧凑 |
| 传感器卡片 | 新增 `sensor-card` 样式，带状态标签 |
| 统计信息 | 改为横向排列的 `stats-row` |
| 调试信息 | 改为 `debug-row` 列表形式 |
| 日志列表 | 限制显示8条，避免过长 |

### 3.3 新增空状态样式

```css
.empty-state {
  text-align: center;
  color: #666;
  padding: 30px;
  font-size: 13px;
}
```

## 四、LidarViewer.vue 修改内容

### 4.1 布局重构

**原布局（有问题）：**
```css
.monitor-grid {
  grid-template-columns: 2fr 1fr;
  grid-template-rows: auto auto;
}
#lidar-visual { grid-row: 1 / 3; }  /* 跨两行 */
#data-log { grid-column: 1 / -1; }  /* 跨两列 */
```

**新布局（修复）：**
```css

  grid-template-columns: 1.2fr 1fr;

  gap: 12px;

.scan-module { grid-row: span 2; }   /* 扫描图占左侧两格 */
.log-module { grid-column: span 2; max-height: 140px; }  /* 日志在底部 */
```

### 4.2 Canvas 尺寸优化

| 元素 | 原尺寸 | 新尺寸 |
|------|--------|--------|
| Canvas | 600x600 | 420x420 |
| 最大半径 | 250 | 180 |

### 4.3 统计卡片优化

新增 `stat-card` 组件，统一展示：
- 图标 + 标签 + 值的组合
- 6个统计项使用 2x3 网格
- 小字体适配长内容

### 4.4 障碍物列表优化

- 限制显示6个
- 添加序号标识
- 进度条颜色根据距离变化

## 八、使用建议

1. **备份原文件**：在替换前备份原始的 `.vue` 文件
2. **逐步替换**：建议先替换 `App.vue`，确认无误后再替换子组件
3. **测试响应式**：在浏览器开发者工具中测试不同屏幕尺寸
4. **检查 ROS 连接**：确保替换后 ROS WebSocket 连接正常
