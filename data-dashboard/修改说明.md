# 项目变更说明

> 记录本系统从早期版本到当前最新版本的主要变更。当前项目最新功能与结构请见 [项目书.md](./项目书.md)。

## 版本演进概览

| 版本 | 说明 |
|------|------|
| v1.0 (早期) | 多传感器独立页面（超声波 / 激光 / 深度相机 / 污渍检测），ECharts 数据大屏雏形 |
| v2.x | 引入数据大屏 Screen1，整合设备状态 / 今日统计 / 实时日志 / 机器人控制 |
| v3.0 | 深度相机接入 Basler 工业相机数据流；界面布局优化（紧凑化、响应式） |
| v4.0 (当前) | 精简为 3 个核心页面；新增全局 ROS 状态、六语言国际化、YOLO 污渍标注服务、STM32 ROS 指令控制 |

## 主要变更内容

### 1. 页面结构调整
- **移除** 激光雷达独立页面（LidarViewer）
- **移除** 独立污渍检测页面（StainDetection）——污渍识别改为 YOLO 后端服务，在工业相机页面直接呈现标注流
- 保留并演进：数据大屏（Screen1）、超声波雷达（UltrasonicRadar）、深度/工业相机（DepthCamera）

### 2. 超声波模块演进
- 早期为单模块演示（3 路传感器卡片 + 基础 Canvas）
- 当前：Canvas 雷达图（4 圈距离刻度、十字线、左/前/右方向标记、<200mm 红警）+ **STM32 ROS 指令控制**（行走 / 转向 / 毛刷启停 / 急停，支持键盘 WASD 与 T/C 键）

### 3. 全局状态与国际化
- 新增 `src/store/rosState.js`（Pinia/reactive）统一管理全局 ROS 连接状态
- 新增 `src/locales/`，内置中 / 英 / 泰 / 马来 / 印尼 / 越南六语言切换（vue-i18n）

### 4. 相机与 AI 检测
- 新增 `src/camera_yolo_server/`：Flask + YOLO（ultralytics）+ OpenCV 对工业相机流逐帧污渍标注
- 前端直接显示 YOLO 标注流（`http://localhost:8083/camera`）

### 5. 依赖调整
- 移除未使用的 `three`、`@tresjs/core`（旧 3D 可视化）、`@playwright/test`（无测试用例）
- 新增 `pinia`、`vue-i18n`、`echarts`
- 删除脚手架默认组件 `src/components/HelloWorld.vue`

### 6. 其它优化
- `vue.config.js` 开发端口设为 8081
- 超声波数据转发服务保留为 `sensor_server.py`（UDP 接收 + WebSocket 转发）
