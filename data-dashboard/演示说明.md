# 智能清洁机器人数据可视化系统 · 演示说明

> 本文档基于当前项目最新版本编写。项目完整说明请见 [项目书.md](./项目书.md)。

## 项目概述

本系统是一个基于 **Vue 3 + ROS 2** 的清洁机器人数据可视化监控平台，通过 WebSocket 实时接入 ROS 2 传感器数据，提供数据大屏、超声波雷达监控、工业相机（YOLO 污渍识别）监控与机器人远程控制。

## 功能演示

### 1. 数据大屏（Screen1）

设备状态总览、机器人作业视图、今日作业统计（ECharts）、实时工作日志，并提供方向键 / WASD 遥控机器人行走与清扫。

### 2. 超声波雷达监控（UltrasonicRadar）

- 通过 roslib 连接 ROS 2（默认 `ws://192.168.0.3:9090`），订阅 `/wave_length`
- Canvas 雷达图：4 圈距离刻度（125 / 250 / 375 / 500mm）、十字线、左/前/右方向标记
- 传感器距离 < 200mm 时扇形与数值变红警告
- 语言切换自动重绘方向标签

**STM32 指令下发**（ROS 话题方式）：

| 指令 | 值 | 键盘 |
|------|----|------|
| 停止 | 1 | 空格 |
| 后退 | 2 | S / ↓ |
| 前进 | 3 | W / ↑ |
| 左转 | 4 | A / ← |
| 右转 | 5 | D / → |
| 毛刷停止 | 6 | C |
| 毛刷启动 | 7 | T |

发布到 `/stm32_cmd`，执行结果回传 `/stm32_result`，STM32 在线状态经 `/stm32_status`（1Hz 心跳）实时显示。

### 3. 工业相机 + YOLO 污渍识别（DepthCamera）

- 前端直接显示本机 YOLO 标注服务的视频流（`http://localhost:8083/camera`）
- YOLO 服务（`camera_yolo_server.py`）读取相机流（`http://192.168.0.3:8082/camera`）逐帧标注污渍

### 4. 多语言国际化

内置中文 / English / ไทย / Bahasa Melayu / Bahasa Indonesia / Tiếng Việt 六语言，顶部一键切换，全局生效。

### 5. 机器人远程控制

Web 端方向键 / WASD 遥控机器人行走，T/C 键启停清扫毛刷，空格急停，指令与结果实时回显。

## ROS 2 话题映射

| 话题 | 消息类型 | 用途 |
|------|----------|------|
| `/wave_length` | `std_msgs/UInt8MultiArray` | 超声波测距数据 |
| `/stm32_cmd` | `std_msgs/Int32` | STM32 指令下发 |
| `/stm32_result` | `std_msgs/String` | 指令执行结果 |
| `/stm32_status` | `std_msgs/String` | STM32 在线心跳 |

## 演示环境准备

```bash
# 1. 安装前端依赖并启动（端口 8081）
npm install
npm run serve

# 2. 启动工业相机 YOLO 标注服务（端口 8083）
cd src/camera_yolo_server
python camera_yolo_server.py --camera http://192.168.0.3:8082/camera --port 8083

# 3.（可选）启动超声波 UDP + WebSocket 转发服务
python sensor_server.py
```

浏览器访问 `http://localhost:8081`。

## 演示要点

1. **实时性**：ROS 数据经 WebSocket 秒级呈现，雷达图随距离实时变色
2. **交互性**：Web 端直接遥控机器人行走 / 清扫 / 急停，指令结果即时回显
3. **AI 能力**：工业相机画面叠加 YOLO 污渍标注框，直观展示识别效果
4. **多语言**：六语言实时切换，适配国际化展示场景
