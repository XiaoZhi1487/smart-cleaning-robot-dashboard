# 超声波雷达数据监控系统 - 核心代码演示

> ⚠️ **历史归档文档**：本文档为超声波雷达模块的早期演示说明（v1.0），仅供参考。当前项目的完整功能与运行方式请以 [项目书.md](./项目书.md) 为准。

## 项目概述

本系统是一个基于 Vue 3 + ROS 2 的超声波雷达数据可视化监控平台，用于实时监控清洁机器人的超声波传感器数据。

## 核心功能演示

### 1. 传感器数据卡片展示（第 55-78 行）

**功能**：以卡片形式展示三个超声波传感器的实时数据

**代码亮点**：
- 使用 `v-for` 循环渲染三个传感器卡片（左、前、右）
- 动态样式绑定：距离过近时显示警告色（红色）
- 实时显示距离数值和状态

**展示效果**：
```
┌─────────┐  ┌─────────┐  ┌─────────┐
│   📡    │  │   📡    │  │   📡    │
│   左    │  │   前    │  │   右    │
│  250mm  │  │  500mm  │  │  180mm  │
│ ⚠️过近  │  │  ✅正常 │  │ ⚠️过近  │
└─────────┘  └─────────┘  └─────────┘
```

**技术要点**：
- Vue 响应式数据绑定
- 动态 CSS 类名绑定（`:class`）
- 条件渲染（距离大于0才显示数值）

---

### 2. ROS 2 桥接连接（第 329-351 行）

**功能**：建立与 ROS 2 系统的 WebSocket 连接

**代码亮点**：
- 使用 `ROSLIB.Ros` 创建 ROS 连接
- 完整的连接生命周期管理（连接、错误、关闭）
- 自动订阅传感器数据话题

**工作流程**：
```
用户点击连接按钮
       ↓
创建 WebSocket 连接 (ws://192.168.0.2:9090)
       ↓
连接成功 → 订阅 /wave_length 话题
       ↓
实时接收传感器数据
       ↓
解析并展示在界面上
```

**技术要点**：
- WebSocket 实时通信
- ROS 2 话题订阅机制
- 连接状态管理（防止重复连接）
- 错误处理和用户提示

---

### 3. 数据解析算法（第 437-462 行）

**功能**：解析 ROS 传来的原始字节数据为距离值

**代码亮点**：
- 处理 Base64 编码的数据
- 位运算解析 16 位距离值（高字节 + 低字节）
- 数据有效性验证

**数据格式说明**：
```
原始数据（6字节）: [0x01, 0x0A, 0x01, 0xF4, 0x00, 0xB4]
                      ↓         ↓         ↓
传感器 1 (左):     0x010A = 266 mm
传感器 2 (前):     0x01F4 = 500 mm  
传感器 3 (右):     0x00B4 = 180 mm
```

**解析过程**：
```javascript
// 每2个字节代表一个传感器
byte1 = 0x01  // 高字节
byte2 = 0x0A  // 低字节

// 位运算组合
distance = (byte1 << 8) | byte2
         = (0x01 << 8) | 0x0A
         = 0x0100 | 0x0A
         = 0x010A
         = 266 mm
```

**技术要点**：
- Base64 解码
- 位运算（左移、或运算）
- 数据类型转换和验证
- 错误处理（NaN 检测）

## 演示要点

1. **实时性**：数据从硬件到界面延迟 < 100ms
2. **可视化**：雷达图直观展示三个方向的障碍物距离
3. **可扩展性**：易于添加更多传感器或功能
4. **稳定性**：完善的错误处理和连接重连机制
